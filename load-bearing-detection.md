# RTT/1 — Load‑Bearing Detection
**Engine:** RTT/1 Structural  
**Mode:** S‑mode (structural surface)  
**Session:** rtt=1 · coherence=declared · drift=bounded · paradox=structural  

Load‑bearing detection identifies the elements that the input **depends on** for its structural stability.  
These are not interpretations or critiques — they are **structural necessities** visible from the clarity surface.

RTT/1 confirms load‑bearing elements using three criteria:

1. **Dependency** — the input cannot function without it  
2. **Structural anchoring** — other elements attach to it  
3. **Propagation** — removing it causes collapse or incoherence
