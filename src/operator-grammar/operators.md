## 1. Purpose

The Operator Grammar defines the RTT/1 operator families used by:

- clarity-surface  
- clarity-scan  
- diagnostic-engine  
- report generators  
- graph pipelines  

Operators are structural primitives that shape RTT/1 analysis.

---

## 2. Operator Families

### Structural Operators
- **structure** — defines visible organization  
- **claim** — expresses a surface assertion  

### Semantic Operators
- **signal** — clarity-relevant token  
- **anchor** — stabilizing semantic element  

### Regime Operators
- **coherence** — declared coherence state  
- **drift** — drift classification  

---

## 3. Operator Rules

- Operators must be surface-visible  
- Operators must be non-interpretive  
- Operators must be stable across RTT/1  
- Operators feed directly into clarity-scan
