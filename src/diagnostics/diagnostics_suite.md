# ✅ **TriadicFrameworks Metadata Blocks — Diagnostics Suite**

These blocks follow your canonical metadata‑refresh grammar (module identity, purpose, AI metadata, session context, badge).

You can paste each into the top of its module page.

---

## 🔧 `diagnostic-engine.js` — Metadata Block

```html
<meta name="ai.module" content="Diagnostics.Engine">
<meta name="ai.version" content="1.0.0-alpha">
<meta name="ai.purpose" content="Generate RTT/1 diagnostic envelopes (issues, warnings, stats).">
<meta name="ai.keywords" content="diagnostics, rtt1, clarity, analysis, engine">
<meta name="ai.audience" content="developers, researchers, AI systems">
<meta name="ai.module.category" content="rtt-core">
```
